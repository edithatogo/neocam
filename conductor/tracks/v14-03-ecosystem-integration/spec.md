# Ecosystem integration: sibling repositories, provenance and privacy patterns

Design authority: [../../v14-design.md](../../v14-design.md).
Implementation scope: the owner maintains many sibling repositories that already solve
parts of this project's problem. This track records which of them are relevant, in what
form each is incorporated (pinned submodule, documented reference, real dependency, or
reused CI pattern), and adopts the privacy/automation patterns that this repository
lacks. It introduces no clinical parameter and no model change; the ViI/VoI integration
task is explicitly gated on decision-utility credibility.

# Use one explicit gate runner for local development and CI

## Scope
User-authorised v3 assurance refinement. No new economic parameters, cohorts or clinical effects. Preserve v2 outputs unless a tested defect requires correction.

## Acceptance
Each implemented step has a named test or command and an evidence path. Missing tool execution is blocked, never passed.

## Dependencies
The existing v2 git history and model are the baseline. Later tracks consume the repaired contracts, pinned release targets and receipt format.

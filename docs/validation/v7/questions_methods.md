# Question-to-method map

| Decision question | Method actually implemented | Limit |
|---|---|---|
| What if the pilot expands within CHHHS or across CHHHS/TCHHS? | Four named hospital/emergency portfolios, historical census plus reopening/readiness scenarios | Not all primary health centres; per-site casemix proxies |
| Who bears costs and who benefits? | Shared-draw component ledger; health, provider, patient/family and fiscal allocation views | Fiscal response illustrative; provider costs before unverified revenue effects |
| Does perspective alter a fixed decision? | Directional expected VoP with explicit source/target ties | Cost-only reference; not a new clinical valuation |
| Could health benefits justify added costs? | Required-QALY thresholds; instrument-separated utility bridge | No video mortality/neurodevelopment effect estimate |
| Could burden data inform the model? | AIHW/EPICure/Victorian source mapping; explicit DALY helper | No neonatal DW/life-table dataset or calibrated DALY estimate |
| Are assumptions influential? | Paired44x20,000-draw regional structures;121-cell allocation surfaces; retained v6 clinical sensitivities | Scenario frequencies are not probabilities; no additional surrogate fitting |
| Is the source archive complete? | Hash manifest, extract/original distinction, retrieval inventory | Public original binary retrieval blocked |
| Is the implementation independently validated? | Simulated role review and ordinary tests | No independent agent/human review claimed |

Main model is an early cost-consequence and investment-threshold analysis. No calibrated lifetime cost-utility, formal causal treatment-effect fit, complete societal valuation, or funding-entitlement model is claimed.

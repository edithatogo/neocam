# Burden-of-disease source use
AIHW Australian Burden of Disease Study2024, summary and technical framework. DALY=YLL+YLD; YLD combines prevalence with sequela-specific disability weights. Projected population disease burden is not intervention-attributable burden.
No neonatal age/condition-specific DALY table or disability-weight source file was downloaded in this environment. Do not use a national all-age DALY total per consultation, convert DW to utility by1-DW, or add QALYs and DALYs. The implemented DALY helper is arithmetic infrastructure, not a calibrated neonatal DALY result.
